# Security Policy

## Supported Versions

This portfolio website is actively maintained. Security updates are provided only for the latest version deployed to production.


## Reporting a Vulnerability

If you discover a security vulnerability in this website, please report it privately by contacting me via the email address listed on my GitHub profile or through the contact information available on this portfolio website, rather than creating a public GitHub issue.

Please include:

* A clear description of the vulnerability.
* Steps to reproduce the issue.
* The affected page or feature.
* Any supporting screenshots or proof of concept (if applicable).

After receiving your report:

* I will acknowledge receipt within 5 business days.
* I will investigate and validate the issue.
* If the vulnerability is confirmed, I will work to resolve it as soon as reasonably possible.
* Once the issue has been fixed, I may request additional verification before considering it resolved.

Please do not publicly disclose security vulnerabilities until they have been investigated and, where appropriate, fixed.

Thank you for helping keep this website secure.
